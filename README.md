# OpenAppSec WAF Installation & Configuration Guide

This repository provides a complete, step‑by‑step guide to installing **OpenAppSec** – a free, machine‑learning‑powered Web Application Firewall (WAF) – on a Linux server.

## What's inside?
- `INSTALLATION.md` – detailed installation instructions (Simple WAF → Advanced ML → Cloud dashboard)
- `config-samples/` – example configuration files for security policies, rate limiting, and API error responses
- `scripts/` – automation scripts to install and connect the WAF

## Why OpenAppSec?
- Free and open‑source (Community Edition)
- Uses ML to block SQLi, XSS, and zero‑day attacks
- Can run as a local agent with optional cloud management

## Quick Start

1. git clone https://github.com/akorir08y/waf-homelab
2. cd waf-homelab
3. cat INSTALLATION.md
